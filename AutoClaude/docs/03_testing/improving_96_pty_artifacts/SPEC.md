# strutils 規格（SPEC）

零依賴的純函式 Python 字串工具庫。本檔以行為契約方式定義 `slugify` 與 `truncate` 兩個函式的對外語意與邊界，作為 TDD 測試與實作的單一事實來源（SSOT）。

---

## 1. `slugify(s: str) -> str`

### 行為契約
1. 將輸入轉為小寫。
2. 將所有空白字元（含 ` `、`\t`、`\n` 等）與底線 `_` 轉為連字號 `-`。
3. 移除所有非 `[a-z0-9-]` 範圍內的字元（例如標點符號、非 ASCII 字元）。
4. 將連續多個 `-` 合併為單一 `-`。
5. 去除字串頭尾的 `-`。
6. 回傳處理後的字串；型別恆為 `str`。

### 處理順序（建議實作順序）
小寫 → 空白/底線換成 `-` → 過濾非合法字元 → 折疊連續 `-` → 去除首尾 `-`。

### 契約範例
| 輸入 | 輸出 |
|---|---|
| `"Hello World"` | `"hello-world"` |
| `"Hello, World!"` | `"hello-world"` |
| `"  Hello___World  "` | `"hello-world"` |
| `"Hello---World"` | `"hello-world"` |
| `"foo_bar baz"` | `"foo-bar-baz"` |
| `"___"` | `""` |
| `"---"` | `""` |
| `"!!!"` | `""` |
| `""` | `""` |
| `"a"` | `"a"` |
| `"A1 B2"` | `"a1-b2"` |
| `"café"` | `"caf"` |
| `"  leading and trailing  "` | `"leading-and-trailing"` |
| `"--hello--"` | `"hello"` |

### 邊界與不變式
- 空字串輸入 → 回傳空字串。
- 全部都是非法字元或全部都是分隔符 → 回傳空字串。
- 輸出永遠不會出現連續的 `-`。
- 輸出永遠不會以 `-` 開頭或結尾。
- 輸出僅可能包含 `[a-z0-9-]` 字元。
- 純函式：相同輸入恆得相同輸出，無副作用。

## 2. `truncate(s: str, n: int) -> str`

### 行為契約
1. 若 `len(s) <= n`，原樣回傳 `s`（不附加任何省略號）。
2. 否則回傳 `s[: n - 1] + "…"`，其中 `"…"` 為單一 Unicode 字元 U+2026（HORIZONTAL ELLIPSIS），使整體輸出長度恰為 `n`。
3. 當 `n < 1` 時，丟出 `ValueError`（不論 `s` 為何）。

### 契約範例
| 輸入 `s` | `n` | 輸出 |
|---|---|---|
| `"hello"` | `10` | `"hello"` |
| `"hello"` | `5` | `"hello"` |
| `"hello world"` | `8` | `"hello w…"` |
| `"abcdef"` | `2` | `"a…"` |
| `"abcdef"` | `1` | `"…"` |
| `"abcdefghij"` | `6` | `"abcde…"` |
| `""` | `5` | `""` |
| `""` | `1` | `""` |

### 邊界與例外
- `n < 1`（含 `n == 0` 與負數）→ `ValueError`。
- 截斷時，省略號為單一字元 `"…"`（U+2026），非三個 ASCII 點 `"..."`。
- 空字串 `s=""`：只要 `n >= 1`，皆回傳 `""`，不附加省略號。
- 輸出長度不變式：截斷分支下 `len(output) == n`；不截斷分支下 `output == s`。
- 純函式：相同輸入恆得相同輸出，無副作用。

---

## 3. 通用約定
- 兩個函式皆為純函式、零外部依賴（僅標準函式庫，建議僅用 `re`）。
- 型別註解需與簽章一致；不接受 `None`（呼叫端責任）。
- 模組對外公開介面：`from strutils import slugify, truncate`。
- 測試以 `pytest` 撰寫，覆蓋上述所有契約範例與邊界（含空字串、超長、最小 n、無法容納 suffix 等）。
