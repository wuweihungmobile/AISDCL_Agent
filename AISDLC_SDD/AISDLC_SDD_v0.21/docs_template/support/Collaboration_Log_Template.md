#### AI 提問 (AI Questions)

**提問時間**: YYYY-MM-DD HH:MM

**提問內容**:

SA Agent (Amanda) 提問：

```
根據您提供的需求，我理解您想開發一個手機記帳軟體 MoneyTracker。
以下是我識別的核心功能：

【功能需求】
1. F-001: 新增收入記錄
   - 使用者可手動輸入收入交易
   - 包含金額、類別、日期、備註等欄位

2. F-002: 新增支出記錄
   - 使用者可手動輸入支出交易
   - 包含金額、類別、日期、備註等欄位

3. F-003: 交易歷史查詢
   - 查看所有交易記錄
   - 支援篩選和排序

4. F-004: 分類管理
   - 新增、編輯、刪除分類
   - 預設分類：食、衣、住、行、育、樂、其他

5. F-010: 統計圖表
   - 月度支出趨勢圖
   - 分類佔比圓餅圖

6. F-015: 預算設定與提醒
   - 設定月度預算
   - 達到 80% 時發送提醒

【非功能需求引導】
為了更好地規劃系統架構，我需要確認以下問題：

1. **使用者規模**
   - 是否需要支援多使用者/多帳號？
   - 是否需要家庭共用功能？

2. **資料儲存策略**
   - 是否需要雲端同步？（跨裝置使用）
   - 是否支援離線使用？
   - 資料儲存位置：本地 / 雲端 / 混合？

3. **平台特性**
   - 是否需要推播通知？
   - 是否需要相機/相簿存取？（拍攝發票）
   - 是否需要定位服務？
   - 是否需要生物辨識 (Face ID / Touch ID)？

4. **整合需求**
   - 是否整合第三方服務？（如：匯率 API、支付服務）
   - 是否需要分享功能？（分享圖表到社群媒體）

5. **記帳 App 特定問題**
   - 是否支援多幣別？
   - 是否需要發票掃描 (OCR)？
   - 是否需要匯率自動更新？

請確認以上理解是否正確，並回答非功能需求問題。
```

#### 使用者回答 (User Response)

**回答時間**: YYYY-MM-DD HH:MM

**回答內容**:

使用者回答：

```
【功能需求確認】
您的理解基本正確！補充幾點：

1. F-001 & F-002: 新增交易時，希望可以附加照片（發票、收據）
2. F-003: 希望能按日期範圍篩選（本週、本月、自訂區間）
3. F-010: 還需要「年度統計」功能
4. 新增功能：F-016 週期性交易（如：每月房租、訂閱服務）

【非功能需求回答】

1. **使用者規模**
   - MVP 階段只需要單一使用者
   - 家庭共用功能可以之後再加

2. **資料儲存策略**
   - MVP 只需要本地儲存（Realm 或 SQLite）
   - 100% 離線可用
   - 雲端同步功能可以 v2.0 再加

3. **平台特性**
   - 需要推播通知（預算提醒）
   - 需要相機存取（拍攝發票）
   - 需要生物辨識（保護財務資料隱私）
   - 不需要定位服務

4. **整合需求**
   - 需要匯率 API（支援台幣、美金、日圓、人民幣）
   - 不需要支付服務整合
   - 需要分享功能（分享統計圖表到 LINE、Facebook）

5. **記帳 App 特定問題**
   - 需要支援多幣別（台幣、美金、日圓、人民幣）
   - 發票掃描 OCR 功能希望有，但如果成本太高可以延後
   - 需要匯率自動更新（每日更新）
```

**回答類型**:
- [x] 確認理解正確
- [x] 補充遺漏需求
- [x] 回答引導問題
- [ ] 提出新問題
- [ ] 其他

#### 決策結果 (Decision Result)

**決策時間**: YYYY-MM-DD HH:MM

**決策內容**:

基於使用者回答，做出以下決策：

**1. 功能需求更新**
- ✅ F-001 & F-002 新增「照片附件」功能
- ✅ F-003 新增「日期範圍篩選」（本週、本月、自訂區間）
- ✅ F-010 新增「年度統計」
- ✅ 新增 F-016「週期性交易」功能

**2. 非功能需求確認**
- ✅ NFR-U-001: 100% 離線功能（本地資料庫）
- ✅ NFR-I-001: 整合匯率 API（支援 4 種幣別，每日更新）
- ✅ NFR-I-002: 社群分享功能（LINE、Facebook）
- ✅ NFR-S-001: 生物辨識支援（Face ID / Touch ID）
- ✅ NFR-C-001: 相機權限（拍攝發票）
- ✅ NFR-I-003: 推播通知（預算提醒）
- ⏸️ 發票掃描 OCR 功能：延後至 v2.0（成本考量）
- ❌ 雲端同步：不納入 MVP（延後至 v2.0）
- ❌ 家庭共用：不納入 MVP（延後至未來版本）

**3. 技術影響**
- 需選擇支援多幣別的本地資料庫架構
- 需整合第三方匯率 API（如 Fixer API 或 ExchangeRate-API）
- 需實現相機權限請求和圖片儲存機制
- 需實現本地推播通知

**4. 優先級調整**
- F-016 (週期性交易) 設為 Should-have（MVP 可考慮）
- 發票掃描 OCR 從 Should-have 降為 Nice-to-have（延後）

## 📝 使用說明 (Usage Instructions)

### 如何使用本模板

1. **建立新協作記錄**
   - 複製「人機協作點」區塊
   - 填寫基本資訊
   - 記錄 AI 提問、使用者回答、決策結果

2. **即時更新**
   - 在協作過程中即時更新本文檔
   - 使用 Markdown 格式確保可讀性

3. **定期審查**
   - 每個階段結束後審查協作記錄
   - 分析協作效率和品質
