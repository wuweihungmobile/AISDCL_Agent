## 📋 文檔目的

本文檔提供 **Greenfield 專案成本評估**（包含 Web App、Mobile App、Backend API、全端應用）的標準化試算表範本，幫助團隊在技術選型階段全面評估各種成本。

### v2.1 更新說明 (2025-11-22)

- 🆕 **新增 Backend API 平台支援**：補充純後端 API 專案的成本項目
- 🆕 **Backend API 成本特性**：無前端成本、重視 API 效能與可擴展性
- ✅ **平台對比更新**：包含 Backend API 與其他平台的成本對比

### v2.0 更新說明 (2025-11-19)

- ✅ **平台無關設計**：從 Mobile App 專用擴展為支援所有平台類型
- ✅ **新增 Web App 成本項目**：域名、CDN、SSL、託管、SEO 工具等
- ✅ **平台對比章節**：Web vs Mobile vs 全端成本對比
- ✅ **N/A 項目處理**：支援標記不適用項目，避免重複計算

### 使用時機

- **階段 3 - 步驟 3.2**: 技術選型與架構草案（與 Tech_Stack_Selection_Report 配合使用）
- **目的**: 確保在技術選型時考慮完整的成本因素，避免後續預算超支

### 使用者

- **PM/PO Agent (Victoria)**: 預算評估與商業決策
- **SD-Architect Agent (Marcus)**: 技術成本評估
- **Dev Agent (David)**: 開發成本評估

### 平台識別與成本項目選擇

**首先確認目標平台**，然後使用對應的成本項目：

| 目標平台 | 使用成本項目 | 專屬成本說明 |
|---------|------------|-------------|
| **Web App** | 通用項目 + 第 6 章（Web 專屬） | 域名、CDN、SSL、Web 託管、SEO 工具 |
| **Mobile App** | 通用項目 + 第 3 章（開發者帳號） | Apple/Google 帳號、App Store 費用 |
| **Backend API** | 通用項目（標記 N/A：前端相關） | 無前端成本、重視 API 效能與負載平衡 |
| **全端應用** | 所有章節 | 結合 Web + Mobile + Backend 成本 |

### 平台成本特性概覽

```
成本結構差異
├── Web App
│   ├── 無應用商店費用
│   ├── 需要域名和託管
│   ├── SEO 和 CDN 成本
│   └── SSL 證書（通常免費）
├── Mobile App
│   ├── 開發者帳號年費
│   ├── 測試裝置成本
│   ├── 無託管成本（純本地）
│   └── 推播服務成本
├── Backend API
│   ├── 無前端開發成本
│   ├── 無應用商店費用
│   ├── 重視 API 效能與可擴展性
│   ├── 資料庫與快取成本較高
│   └── API 文件與測試工具
└── 全端應用
    ├── 結合以上所有成本
    ├── API 服務成本
    └── 跨平台同步成本
```

## 💡 成本優化建議

### 降低開發成本

1. **使用跨平台框架**
   - React Native / Flutter 可節省 30-40% 開發成本
   - 單一 codebase，維護成本更低

2. **充分利用免費服務**
   - Firebase: 免費的推播、分析、錯誤監控
   - GitHub Actions: 2,000 分鐘/月 CI/CD 免費額度
   - Netlify/Vercel: 免費的靜態網站託管

3. **MVP 優先**
   - 先開發核心功能，延後次要功能
   - 減少初期開發時程與成本

4. **使用開源套件**
   - UI 組件庫（React Native Paper, Flutter Material）
   - 圖表庫（Victory Native, FL Chart）
   - 節省開發時間

---

### 降低營運成本

1. **選擇本地優先架構**
   - 如 MoneyTracker，純本地 App 無雲端成本
   - 僅在需要時才加入雲端同步

2. **延遲付費服務使用**
   - 初期充分利用免費額度
   - 使用者規模達門檻再升級付費版

3. **選擇性價比高的雲端供應商**
   - 比較 AWS, GCP, Azure 價格
   - 考慮 DigitalOcean, Linode 等低成本選項

4. **自動化維護流程**
   - CI/CD 自動化測試和部署
   - 自動化監控和告警
   - 減少人工維護成本
