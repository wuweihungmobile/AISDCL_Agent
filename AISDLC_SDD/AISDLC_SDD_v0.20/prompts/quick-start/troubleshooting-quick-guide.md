## 🚨 初始化問題

```

我想開始使用 SDD Spec-First 流程，請提供 5 分鐘快速體驗。
```

### 問題 2：不確定要選哪個場景
```
我的任務是：[描述]

請根據 AISDLC_SDD_v0.01/scenarios/README.md 協助我選擇場景，
並說明需要通過哪些 SCG 閘門。
```

## 🔴 SCG 閘門問題

### 問題 3：SCG 閘門失敗，不知道如何修復
```
SCG-[N] 閘門驗證失敗。

失敗項目：[列出失敗項目]
當前文件：[路徑]

請協助我識別缺失內容並修復文件，再重新執行閘門驗證。
```

### 問題 4：不確定現在應該通過哪個 SCG 閘門
```
請告訴我當前專案的 SCG 閘門狀態。

已完成的文件：
- [文件 1]
- [文件 2]

下一個應該通過哪個閘門？需要準備哪些文件？
```

### 問題 5：想跳過 SCG 閘門（緊急情況）
```
⚠️ 我了解 Spec-First 原則，但當前有緊急情況需要暫時跳過 SCG-[N]。

原因：[說明緊急原因]
風險承擔：[我確認這是有意識的決策]

請記錄此技術債（TD-XXX），並在 ADR 中標記此偏差。
```

## 🔄 Workflow 執行問題

### 問題 6：Workflow 中斷，需要恢復
```
我在執行 [情境] 的 Workflow 時中斷了。

已通過閘門：SCG-[N]
已完成文件：[列出]
中斷位置：[階段 X]

請從中斷點繼續，確認文件狀態後再推進。
```

### 問題 7：不確定當前在哪個 SDD 階段
```
請顯示當前 SDD 流程進度：
- 已通過的 SCG 閘門
- 已完成的文件
- 下一個待執行步驟
```

考慮過的選項：[列出]

```

### 問題 9：RTM 覆蓋率不足（SCG-5 失敗）
```
RTM 覆蓋率未達 100%，SCG-5 失敗。

未覆蓋的需求：[F-XXX 列表]

請使用 rtm-generate skill 補充對應的測試案例（TC-XXX），

```

### 問題 10：OpenAPI 規格凍結後需要修改
```
SCG-3 已通過（API Contract Frozen），但需要修改 API。

修改原因：[說明]
影響範圍：[受影響的端點]

請依 SDD 規則：
1. 建立 API-COMPAT 聲明
2. 設定廢棄期
3. 補充 ADR 記錄此決策
4. 重新執行 SCG-3 驗證
```

## ⚡ Token 與效能問題

我會在新的對話中繼續。
```
