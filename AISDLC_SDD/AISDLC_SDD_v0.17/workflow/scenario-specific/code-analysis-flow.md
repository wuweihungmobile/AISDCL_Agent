# Code Analysis Flow
# 代碼分析流程

## Workflow 名稱
**code-analysis-flow** - 既有代碼深度分析流程

## 描述
系統性分析既有代碼，識別架構、代碼品質、技術債、安全漏洞和改進機會。

## 適用場景
- **使用時機**：接手既有專案、代碼審查、技術債評估
- **適用專案**：Legacy 系統、維護專案、新團隊接手
- **執行頻率**：專案接手時、定期審查（每季/每年）

## 觸發條件
- 需要理解既有代碼
- 代碼庫可存取
- 分析目標明確

---

# 角色與責任

## 主要負責人
**Agent 角色**：Code-Analyzer + SD
**責任**：代碼分析、架構識別

## 參與者
- **Dev-Senior**：代碼解讀協助
- **Security-Specialist**：安全性分析

# 執行步驟

## 步驟 1：代碼庫掃描與基本分析 (40-60 分鐘)
**執行者**：Code-Analyzer

**作業內容**：
1. 目錄結構分析
2. 技術棧識別
3. 代碼行數統計
4. 依賴分析
5. 語言和框架版本識別

**確認點** 🔴：基本分析確認
- 驗證技術棧識別
- 補充背景資訊

**產出**：代碼庫概覽報告、技術棧清單

## 步驟 2：架構與設計模式識別 (1-1.5 小時)
**執行者**：Code-Analyzer + SD

**作業內容**：
1. 架構模式識別（MVC/MVVM/分層等）
2. 模組劃分分析
3. 資料流分析
4. 設計模式識別
5. 繪製架構圖

**確認點** 🔴：架構分析確認
- 審查架構圖
- 確認模式識別
- 補充設計意圖

**產出**：系統架構分析、架構圖、設計模式清單

## 步驟 3：代碼品質與技術債分析 (1-1.5 小時)
**執行者**：Code-Analyzer

**作業內容**：
1. Code Smell 檢測
2. 複雜度分析（Cyclomatic/Cognitive）
3. 重複代碼檢測
4. 技術債量化（SQALE）
5. 測試覆蓋率分析

**確認點** 🔴：品質分析確認
- 審查品質報告
- 確認問題優先級

**產出**：代碼品質報告、技術債評估、改進建議

## 步驟 4：安全性分析 (30-40 分鐘)
**執行者**：Code-Analyzer + Security-Specialist

**作業內容**：
1. 安全漏洞掃描
2. 依賴安全性檢查
3. 敏感資料處理檢查
4. 認證授權機制分析

**確認點** 🔴：安全性確認

**產出**：安全性分析報告、漏洞清單

## 步驟 5：效能與可擴展性分析 (30-40 分鐘)
**執行者**：Code-Analyzer + Dev-Senior

**作業內容**：
1. 效能熱點識別
2. 資料庫查詢分析
3. 記憶體洩漏風險
4. 可擴展性評估

**產出**：效能分析報告、優化建議

## 步驟 6：改進建議與路線圖 (40 分鐘)
**執行者**：SD + Code-Analyzer

**作業內容**：
1. 整合所有分析結果
2. 優先級排序
3. 制定改進路線圖
4. ROI 評估

**確認點** 🔴：改進路線圖確認

**產出**：綜合分析報告、改進路線圖、ROI 分析
