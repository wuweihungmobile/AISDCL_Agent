## 📌 目的

定義專案 MVP（Minimum Viable Product）範圍，在 **SCG-0 需求凍結前**確認最小可行範圍。

**SDD 使用方式**：
1. 填寫本文件，確認 MVP 範圍
2. 與 PRD/FRD 同步（MVP 範圍對應 F-XXX 需求）
3. 通過 SCG-0 後凍結，Phase 2+ 功能進入 Backlog
