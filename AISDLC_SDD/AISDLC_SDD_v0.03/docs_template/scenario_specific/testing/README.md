# Testing Scenario Templates

**狀態**: 🚧 待補充（預留目錄）

## 目錄用途

此目錄用於存放**測試策略情境**相關的文檔模板。

對應情境：[scenarios/testing/](../../../scenarios/testing/)

注意：此處為**情境專屬測試模板**，與核心測試模板 (core/tests/) 不同，著重於測試策略與計劃。

## 預計包含的模板

- [ ] Test_Strategy_Document_Template.md - 測試策略文檔模板
- [ ] QA_Plan_Template.md - QA 計劃模板
- [ ] Regression_Test_Plan_Template.md - 回歸測試計劃模板
- [ ] Exploratory_Test_Charter_Template.md - 探索式測試章程模板
- [ ] Load_Test_Plan_Template.md - 負載測試計劃模板
- [ ] UAT_Plan_Template.md - 使用者驗收測試計劃模板
- [ ] Defect_Management_Plan_Template.md - 缺陷管理計劃模板

## 開發計劃

- **預計版本**: v0.01+
- **優先級**: P2 (Medium)
- **依賴**: scenarios/testing/ SOP 完善後再建立對應模板

## 與核心測試模板的區別

| 模板類型 | 核心測試模板 (core/tests/) | 情境測試模板 (此目錄) |
|---------|--------------------------|---------------------|
| **用途** | 具體測試案例與報告 | 測試策略與計劃 |
| **範例** | AT_Module_Template, Test_Report_Template | Test_Strategy, QA_Plan |
| **層級** | 執行層 (Execution) | 規劃層 (Planning) |
