## 典型使用場景

1. **前端效能優化**:
   - 頁面載入速度優化
   - Bundle size 優化
   - 渲染效能優化

2. **後端效能優化**:
   - API 回應時間優化
   - 資料庫查詢優化
   - 快取策略設計

3. **系統擴展性**:
   - 水平擴展設計
   - 垂直擴展計劃
   - 微服務拆分
