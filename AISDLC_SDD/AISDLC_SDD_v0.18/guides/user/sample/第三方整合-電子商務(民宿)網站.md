# AISDLC 第三方整合實戰範例：民宿預訂網站

**版本**: v0.01
**最後更新**: 2025-12-16
**情境**: 第三方整合 (Integration)
**平台**: Web (電子商務)
**技術棧**: React (Next.js) + Spring Boot + PostgreSQL + Google Cloud


> **SDD v0.01 使用者提示**：本指南基於 AISDLC-SDD v0.01。使用 AISDLC-SDD v0.01 時，請同時參考對應場景的 SDD Enhancement 文件（`scenarios/{scenario}/SDD_{SCENARIO}_ENHANCEMENT.md`），並確認所有 SCG 閘門步驟已整合到您的工作流程中。

## 📋 範例概述

本文檔展示如何使用 **AISDLC-SDD v0.01** 在 **Cursor AI** 環境中，透過 **Claude Code** 開發民宿預訂網站，涵蓋從專案設定到完整開發流程。

**技術棧**:
- **前端**: React 18 + Next.js 14 (App Router)
- **後端**: Spring Boot 3.2 + Java 17
- **資料庫**: PostgreSQL 15
- **部署**: Google Cloud (Cloud Run + Cloud SQL)
- **第三方整合**: Google Maps API, Stripe Payment, Firebase Auth

---

## 🎯 第一部分：環境設定

### 步驟 1.1: 設定 Cursor AI 專案路徑

**1.1.1 創建專案目錄**

```bash
# 創建 Monorepo 結構
mkdir -p ~/projects/BnBBooking
cd ~/projects/BnBBooking

# 創建前後端子專案
mkdir -p frontend backend
mkdir -p infrastructure/terraform

# 創建共用文檔目錄
mkdir -p docs/{requirements,design,api,tests}
```

**1.1.2 在 Cursor 開啟專案**

```bash
cursor ~/projects/BnBBooking
```

或：
1. 開啟 Cursor AI
2. File → Open Folder
3. 選擇 `~/projects/BnBBooking`

---

### 步驟 1.2: 安裝設定 AISDLC-SDD v0.01

**1.2.1 建立符號連結**

```bash
cd ~/projects/BnBBooking
ln -s ~/projects/AISDLC_ALL/AISDLC_v0.09 ./AISDLC

# 驗證
ls -la | grep AISDLC
```

**1.2.2 創建 CLAUDE.md**

```bash
cat > CLAUDE.md << 'EOF'
# BnBBooking 專案指引

**專案名稱**: BnBBooking (民宿預訂平台)
**AISDLC 版本**: v0.01
**開發情境**: 第三方整合 (Integration)

## 專案架構

- **前端**: Next.js 14 (App Router) + TypeScript + Tailwind CSS
- **後端**: Spring Boot 3.2 + JPA + PostgreSQL
- **部署**: Google Cloud Run + Cloud SQL
- **第三方服務**:
  - Google Maps API (地圖顯示、地址搜尋)
  - Stripe (金流處理)
  - Firebase Auth (使用者認證)
  - SendGrid (Email 通知)

## AISDLC 框架路徑

- **框架位置**: `./AISDLC/`
- **文檔輸出**: `./docs/`

## 開發規範

1. 前後端分離架構，透過 RESTful API 溝通
2. 所有需求文檔遵循 AISDLC PRD/FRD 模板
3. API 設計遵循 AISDLC API 規格模板
4. 使用 AISDLC Integration 情境 SOP

## Monorepo 結構

```
BnBBooking/
├── frontend/          # Next.js 專案
├── backend/           # Spring Boot 專案
├── infrastructure/    # Terraform IaC
├── docs/              # AISDLC 文檔
└── AISDLC/            # 符號連結
```

## 重要提醒

- 執行任何 workflow 前，先讀取 `AISDLC/AISDLC_INIT.md`
- 使用 Integration Scenario: `AISDLC/scenarios/integration/SOP.md`
- API 文檔必須使用 `AISDLC/docs_template/core/api/API_Specification_Template.md`
EOF
```

**1.2.3 初始化前後端專案**

```bash
# 前端 - Next.js
cd frontend
npx create-next-app@latest . --typescript --tailwind --app --no-src-dir

# 後端 - Spring Boot (使用 Spring Initializr)
cd ../backend
# 或在 start.spring.io 下載後解壓縮至此目錄
```

**1.2.4 創建文檔目錄結構**

```bash
cd ~/projects/BnBBooking
mkdir -p docs/{requirements,design,api,tests}
mkdir -p docs/{analysis,planning,reports}
```

## 🔍 常見問題 (FAQ)

### Q1: Stripe Webhook 在本地開發如何測試？

**A**: 使用 Stripe CLI
```bash
# 安裝 Stripe CLI
brew install stripe/stripe-cli/stripe

# 登入
stripe login

# 轉發 Webhook 到本地
stripe listen --forward-to localhost:8080/api/v1/payments/stripe/webhook

# 觸發測試事件
stripe trigger payment_intent.succeeded
```

---

### Q2: Google Maps API Key 如何限制使用？

**A**: 在 Google Cloud Console 設定:
1. API 限制: 只啟用 Maps JavaScript API, Geocoding API, Places API
2. 應用程式限制: 設定允許的網域 (例: bnbbooking.com)
3. 配額: 設定每日請求上限

---

### Q3: Firebase Auth 如何與後端 JWT 整合？

**A**: 流程:
```
1. 前端: 使用 Firebase Auth 登入 → 取得 Firebase ID Token
2. 前端: 將 ID Token 傳給後端 /api/v1/auth/firebase/callback
3. 後端: 驗證 Firebase ID Token (使用 Firebase Admin SDK)
4. 後端: 創建使用者 (如不存在) → 生成自己的 JWT
5. 前端: 儲存 Backend JWT，後續 API 使用此 Token
```

---

### Q4: PostgreSQL 資料庫遷移如何管理？

**A**: 使用 Flyway
```xml
<!-- pom.xml -->
<dependency>
    <groupId>org.flywaydb</groupId>
    <artifactId>flyway-core</artifactId>
</dependency>
```

遷移腳本放在: `backend/src/main/resources/db/migration/`
- V1__initial_schema.sql
- V2__add_user_preferences.sql
