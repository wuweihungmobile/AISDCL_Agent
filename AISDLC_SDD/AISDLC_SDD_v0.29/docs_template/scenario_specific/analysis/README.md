# Analysis Scenario Templates

**狀態**: ✅ 已建立核心模板

## 目錄用途

此目錄用於存放**需求分析與系統分析情境**相關的文檔模板。

注意：此處為**情境專屬分析模板**，與核心 PRD/FRD/SRD 不同，著重於特定分析場景。

## 預計包含的模板

- [x] Legacy_System_Analysis_Template.md - 既有系統分析模板 ✅
- [x] Gap_Analysis_Template.md - 差距分析模板 ✅
- [ ] Feasibility_Study_Template.md - 可行性研究模板（預留 v0.01+）
- [x] Impact_Analysis_Template.md - 影響分析模板 ✅
- [ ] Stakeholder_Analysis_Template.md - 利益相關者分析模板（預留 v0.01+）
- [ ] As-Is_To-Be_Analysis_Template.md - 現狀與目標分析模板（預留 v0.01+）

## 開發計劃

- **已完成版本**: v0.09（3 個核心模板）
- **剩餘模板**: v0.01+（Feasibility, Stakeholder, As-Is/To-Be）

## 與核心模板的區別

| 模板類型 | 核心模板 (core/) | 情境分析模板 (此目錄) |
|---------|----------------|---------------------|
| **用途** | 標準開發流程文檔 | 特定分析場景文檔 |
| **範例** | PRD, FRD, SRD | Legacy 系統分析、差距分析 |
| **使用頻率** | 每個專案必用 | 視情境選用 |
