| 可能性 \ 影響 | 🟢 低影響 | 🟡 中影響 | 🔴 高影響 | ⚫ 極高影響 |

### 影響程度定義

| 等級 | 描述 | 範例 |
|------|------|------|
| 🟢 低 | 單一功能受影響，不影響核心流程 | UI 顯示異常、非核心功能失效 |
| 🟡 中 | 多個功能受影響，有替代方案 | 報表延遲、次要 API 失效 |
| 🔴 高 | 核心業務流程中斷 | 訂單無法建立、支付失敗、資料不一致 |
| ⚫ 極高 | 資料損壞/遺失，系統完全不可用 | DB 損壞、安全漏洞、全系統宕機 |
