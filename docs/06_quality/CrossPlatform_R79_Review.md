# R79 四方複審結論（2026-08-07）

> **為何這份檔存在**：R79 的四方複審在當輪是**純 agent 派工、不落任何 rc**，於是三位複審者
> 各自寫下同一句話——「複審本身沒有磁碟產物，R80 無法從樹上重讀 finding 全文」。
> 交棒書 §0 第 3 點當時只能掛一個 `handoff-claim-verified:` 逃生口說明它為何無法現查。
> 本檔把那個逃生口換成**可現查的東西**：結論、逐筆 finding 標題、以及每一筆的處置。
> 體例照 R78 的同名檔。
>
> 🔴 **它的證據強度上限講清楚**：本檔是**複審結論的轉錄**，不是複審本身的機械記錄。
> 它證明得了「複審跑過、結論是什麼、每一筆怎麼處置」，證明不了「轉錄沒有失真」——
> finding 全文的原件只存在於當輪 session 的交件回報裡。要更強的取證，得讓派工本身落檔，
> 那是 R80 的事（已列進交棒書）。

## 4. 被駁回的五筆（懷疑論複驗後不成立）

每一筆都由第三方以證偽立場重跑過，**量測可重現、但承載結論的那句話為假**：

1. **額度事件段住在不用它的 hook 裡**（Architect）——量測為真，但用來支持該擺法的那句論證
   被同一支檔自己推翻，且建議修法是 ADR 已明文否決的方案。
2. **S3 的頭號數字方向是反的**（SA）——把「本機預設路徑」偷換成一個 R79 之後已不是預設的剖面，
   於是把一個大幅下降的結果講成小幅退步。
3. **Q4 的歸因百分比同日內漂移**（SA）——三個支柱全倒，其中歸因方向的錯誤用 SA 自己的證據即可證偽。
4. **M5 兩輪停在 50%**（SA）——引用了本輪自己刪掉的判準。
5. **`DEF-101-796` 攔阻矩陣是載體瞄錯位置的產物**（SD）——中心主張被磁碟現況直接推翻：
   作者已在表格**緊接其下**明文寫「這個數字不是攔阻率量測值，本列因此不結案」。

> 🔴 **駁回不等於沒有價值**：第 5 筆的量測（載體的注入沙盒不在護欄層真實掃描面內）為真，
> 且已寫進交棒書 §4.2 當作 R80 實跑前必須先確認的連動點。

| stdio-UTF-8 去重棘輪由基線升一 | 同上；且**第一次修它時修錯了**——見下 |

🔴 **最後一筆值得單獨記**：把那個第二份實作換掉之後棘輪**仍然紅**，因為解釋「我為什麼不用它」的
那段註解**把被禁的呼叫逐字拼了出來**，而去重棘輪掃的是原始碼字面、不分程式碼與註解。
⇒ **在被機械判讀的面上，解釋 X 的字面等於又用了一次 X。** 這與 R73 立的
「訂正註記逐字引述假話＝製造新假話」是同一條規則的另一個面向，本輪是它第一次長在
「掃描器數字面」而不是「讀者讀語意」上。
