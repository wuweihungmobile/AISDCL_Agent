> 依「發現即記、絕不累積」紀律入帳，並依分流規則回流改進（見
> `docs/04_planning/AutoSDD_Iteration_Prompt_Template.md` 的「🐶 自我迭代模式」）。
> **建立**：2026-06-12（首輪 N=01；首輪或帳本不存在時於階段一建立含表頭的帳本）。

> `ID`｜`發現日期`｜`發現情境`（FSM 狀態 / SCG 閘門 / hook / skill / nightly stage / 審計）｜
