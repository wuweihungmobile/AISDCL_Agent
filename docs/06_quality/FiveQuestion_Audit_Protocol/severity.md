## 家族與計數（登記制，反 Goodhart）
- 「家族」不由帳本欄位決定（帳本只有自由文字的發現情境）；改採登記：輪帳本每列的 `new_p_le2`
  （計入新）與 `excluded_p_le2`（排除，須附理由）。
- 完整性閘：帳本內「發現日期落在該輪窗口、嚴重度 ∈ {P1,P2}」的每一列，必須出現在該輪的
  `new_p_le2` 或 `excluded_p_le2`；兩者皆無＝機械紅。「不算家族」是一個要寫下理由的動作，不是預設。
- 拆殘：新列所引的缺陷編號，若與上一輪收尾 commit 的帳本快照中未結集合有交集，視為既有未結列的
  新證據（不計新）；引的是已結案列、或無引用者，計新。已結案列的同根變體計入。
- 「同根變體是否成立」「P2 或 P3」屬人供判斷，須在報告寫出依據。
