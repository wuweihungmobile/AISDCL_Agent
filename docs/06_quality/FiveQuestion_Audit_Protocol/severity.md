# 嚴重度口徑、暴露度與家族計數（輪不變）

## 嚴重度
- P1：本體缺陷，即掌舵者症狀本身——收斂型工具（Read／Write／Edit／Bash…）被錯誤硬擋，且一次呼叫內
  無出口。判決 REJECT。
- P2：錯誤決策／漏攔／誤擋，**且有暴露證據**（見〈暴露度〉）。判決 CONDITIONAL。
- P3：訊息誤導，但一次呼叫內即可恢復；與附屬細節（行號、措辭、歸屬）只列不改判。
- P4：理論洞——構造出來、無暴露證據的誤擋／漏攔／錯誤決策（見〈暴露度〉）。只登記、不立輪、不同輪修。
- 量測器缺陷在「被判準直接消費」的瞬間升一級：量錯的尺會產生錯誤決策。

## 暴露度（P2 的必要條件）
「同根變體」不是嚴重度：血統只決定家族歸屬，暴露度才決定 P2 或 P4。暴露證據＝下列任一：
- (a) 掌舵者真機回報（sid＋seq，或畫面字樣）；
- (b) 非構造性逐字稿——真實互動窗（entrypoint cli／claude-vscode）或症狀探針（PA／PB／PC，首則 prompt 為
  自然任務）——中實際發生的誤擋／漏攔／錯誤決策（`is_error` 且帶 `toolDenialKind`；或真 rc≠讀值且後續依錯值行動）；
- (c) 真實語料重放（`tools/probe/shell_command_corpus.py --corpus transcripts`）在**非探針種子**指令上命中
  ≥ `exposure_min_hits` 筆（帶 `cmd /c exit N`、`R*-PROBE` 等探針印記的指令不算）。
構造性命中（變體矩陣、答案表新列、對抗語料、審查角色自己造的指令）只證明「理論上可能」＝P4，寫進證據檔
〈理論洞清單〉（形態／來源／暴露度量法與結果）；日後任一暴露證據出現即升 P2 立列。
WHY：R194～R196 三輪（DEF-200-481→483→484）各一個 P2，其中 483／484 在 9,646 筆真實 PowerShell 唯一指令上
自然寫法命中 0、差分 13 筆全帶探針種子；沒有暴露軸，零命中的理論洞可以無限供應，收斂宣告永遠關不上
（R197 證據檔〈四〉）。
