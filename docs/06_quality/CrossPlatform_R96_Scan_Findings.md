**入場結論**：入場的 8 筆紅 ＋ 1 筆天花板不合格，逐筆歸因後都是
「單平台專屬判準在對面平台失效」——對應 `DEF-200-149`~`DEF-200-155`，即 Closure_Evidence §2 的**七筆**。

🔴 **這句話的射程只到這裡（R96 複審訂正，QA）**：原文寫「**無一例外**」而緊接著的 §B 列了
**九**筆，讀者會把兩者相乘。實際上 §B 另列的 `DEF-200-156`（節流訊息缺欄位）與 `DEF-200-157`
（cap 無模型維度）**根本不是本輪閘門的紅**，而是掌舵者質疑觸發的額度演算法缺陷，
**兩者都沒有平台維度**（在 mac 上一樣壞）⇒ 不得併進上面那個分母。拿它們去灌大分母，
再用大分母去支撐「本機全綠的證據力等於零」，是把樣本灌水。
另 `DEF-200-155` 自陳**不是程式缺陷、是判準的結構性後果**，引用時要一併帶著這個限定。

逐筆歸因見 Closure_Evidence §2；共同形態（失效方向永遠是「在寫它的那台機器上看起來是綠的」）見同檔 §2 開頭表。

## §C 治理層對帳：為何這一輪的紅是**可預測的**

三因相乘（詳見 Closure_Evidence §4，含五項改善方案與其成本排序）：

1. 單平台專屬的鎖只有在該平台真機上才會被執行 —— 最貴實例＝`DEF-200-149`。
2. 兩次切換之間本該有的看守者已死 —— `windows-compat-ci` / `macos-compat-ci` 的 run
   `steps=0`，never-started 比例 74%／64% ⇒ 這段期間「push 軌全綠」宣稱一律不成立。
3. 部分棘輪的分母隨對面平台工作而變、卻只在本平台量得到 —— `DEF-200-155` 是純粹實例，
   且它**不是缺陷、是判準的結構性後果**，反方向完全同構。

### §F-① `SentinelWiringTest` 的負向／正向等待時間不同源、無方向鎖（QA）

  ④ 與 ⑤ 的 `os.path.realpath()` 逐字相同、判決卻相反 ⇒ 缺口不是理論的。

  與本檔其餘劃界條目多為 fail-closed **相反**。
- 🔴 **為什麼還是要登記**：根 `CLAUDE.md` 明文宣告「擋不到什麼的**唯一真相源**＝
  `block_destructive_git.py` 檔頭〈誠實劃界〉節」。缺這一條，失真的不只是一個守衛，而是那句
  **SSOT 宣稱**本身。

  模組 docstring 該節已有「🔴 但 `..` 穿越不在射程（放行方向的 fail-open）」一句，
  `_DISPOSABLE_WT` 旁另有逐行實測與「本輪只記不修」的理由）；帳本索引由 D1 併入 `DEF-200-172` ⑦。

  `python tools/probe/shell_command_corpus.py --corpus transcripts` 的假紅普查一起做。P3、承接 R97。

#### §F-⑦-a 🔴 第 ⑪ 波補登的**新事實**：R96 這一輪把這個缺口**變寬了**（本波當回合親自重現）

上表 ④⑤⑥ 三個形態全部是**反斜線**寫法。第四輪簽字輪有兩位審查員各自獨立指出同一件事：
**正斜線**寫法在 R96 之前是**被擋**的，`normcase` 落地之後才變成**放行**。本波不採信轉述，
以唯讀探針直呼 `_worktree_hit(["remove","--force",<路徑>], None)`（**未執行任何 git**）重現，
當回合實測輸出逐字如下（`platform=win32`、`_DISPOSABLE_WT='.claude\\worktrees\\'`）：

| | 目標 | `is_foreign` | `prefix_in`（R96 後，帶 `normcase`） | `prefix_in`（R96 前，無 `normcase`） | 現行判決 |

| ④ | `<repo>\AutoClaude` | False | False | False | 阻擋 |

  這條繞行路也一起打開了。兩件事共用同一個 `in` 判準，所以修一個必然動到另一個。

  - **本波處置**：帳本 `DEF-200-172` 的嚴重度欄就地標成 `P3（⑦ 待複評）`（零新增列——未結列

### §F-⑧ 生產側 `setup_logger` 換 `log_dir` 會靜默沿用舊握把，而**一個鎖都沒有**（QA／SD 於簽字輪各自實查；第 ⑪ 波補登）

  > （該列目前只記到測試側，生產側這一半需另立）。

- **生產側缺陷本體（本波 Read `AutoClaude/autoclaude/utils/logger.py` 親自複核，第 34～44 行）**：


  「換 `log_dir` 第二次呼叫必須寫進新目錄」的回歸鎖。⚠️ 這是**行為改動**，須有複審接住。
